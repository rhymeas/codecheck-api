EORI validation

EORI customs number format — checksum: EORI format (country code plus customs identifier). Free in your browser, or over the JSON API.

What it is

EORI customs number format. CodeCheck verifies three things separately — format, length and check digit — and returns the expected and provided check digit, so a failed value tells you exactly what is wrong instead of just saying no.

Algorithm

EORI format (country code plus customs identifier). The answer is derived from the value itself, with no database lookup and no third-party call, so it is deterministic, fast and privacy-safe.

API

curl "https://<your-worker>.workers.dev/v1/validate/eori/DE123456789012345"

This type has no single trailing check digit, so there is no completion endpoint for it. Validation still reports format, length and any check digits found.
